# 📚 Library Management System using OOP

## 📌 Project Overview

The **Library Management System** is a Python-based application developed using **Object-Oriented Programming (OOP)** concepts to manage books, library members, and borrowing activities.

The system provides basic functionality for adding and managing books, registering members, issuing and returning books, and tracking book availability.

## 🎯 Objectives

* Manage library books efficiently.
* Register and manage library members.
* Issue books to members.
* Return issued books.
* Track book availability.
* Demonstrate practical implementation of OOP concepts.
* Build a structured and maintainable Python application.

## 🛠️ Technologies Used

* **Python**
* Object-Oriented Programming
* Classes & Objects
* Encapsulation
* Inheritance
* Methods
* Lists / Dictionaries
* Conditional Statements
* Exception Handling

## ⚙️ Main Features

### 📖 Book Management

* Add new books.
* Store book details.
* Display available books.
* Track issued and returned books.

### 👤 Member Management

* Register library members.
* Store member information.
* Display member details.

### 🔄 Book Issue

* Issue an available book to a registered member.
* Update book availability after issuing.

### ↩️ Book Return

* Return previously issued books.
* Update book availability automatically.

### 🔍 Availability Tracking

The system checks whether a book is currently available before allowing it to be issued.

## 🧱 OOP Concepts Used

### 1. Classes & Objects

Created classes to represent different entities such as:

```python

    pass

class Member:
    pass

class Library:
    pass
```

Objects are created from these classes to manage individual books, members, and library operations.

### 2. Encapsulation

Data and related methods are grouped within classes to keep the application organized and protect object data.

### 3. Inheritance

Inheritance can be used to create specialized classes from a common parent class and reduce code duplication.

### 4. Methods

Methods are implemented for operations such as:

* Adding books
* Registering members
* Issuing books
* Returning books
* Checking availability
* Displaying records
